# 토지 양도소득세 계산기 (참고용)

숫자만 넣으면 **사업용·비사업용 토지**의 양도소득세 차이를 바로 비교해 주는 웹 계산기입니다.

> ⚠️ 참고용 계산기입니다. 실제 신고 전에는 반드시 세무 전문가와 확인하세요.

## 사용 방법

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다. 설치는 필요 없습니다.

입력 항목:
- 취득가액
- 양도가액
- 필요경비 (중개수수료·취득세 등)
- 보유기간
- 토지 구분 (사업용 / 비사업용)

## 여러 기기에서 작업하는 규칙

데스크탑, 노트북, 모바일(Claude 앱)에서 함께 작업합니다. 기준점은 이 GitHub 저장소입니다.

| 기기 | 방법 |
|---|---|
| 데스크탑 / 노트북 | 로컬 Claude Code에서 작업 |
| 모바일 | Claude 앱 클라우드 세션에서 작업 (PC가 꺼져 있어도 됨) |

**규칙: 시작할 때 pull, 끝날 때 push**

```bash
git pull   # 작업 시작 전: 최신 코드 받기
git push   # 작업 끝난 후: 고친 내용 올리기
```

모바일(클라우드) 작업은 `claude/...` 브랜치에 올라갑니다. PR을 만들어 `main`에 Merge해야 다른 기기에서 받을 수 있습니다.
